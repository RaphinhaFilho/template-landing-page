# Project Instructions for AI Agent

## Primary Rule
Read `DESIGN.md` and `src/app.css` before writing or modifying any layout or UI component.

## Implementation Guidelines
1. **Design System Adherence:** Follow the exact tokens, color variables, and `border-radius` rules defined in `DESIGN.md`.
2. **Tailwind v4 Utility Tokens:** Use Tailwind v4 class names matching the defined theme variables. Avoid arbitrary utility values (e.g., avoid `bg-[#123456]` or `p-[13px]`).
3. **High-Converting Elements:** Ensure main CTAs are visible above the fold, lead directly to WhatsApp links (`https://wa.me/...`), and have hover/active micro-interactions.
4. **Mobile First:** Ensure responsive behavior on mobile viewports (375px+) with zero horizontal scrolling.
5. **No AI Clichés:** 
   - No generic gradients unless defined in `DESIGN.md`.
   - No placeholder "Lorem Ipsum" text — use real-world local business context for Campina Grande, PB.
